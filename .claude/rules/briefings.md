# Rules for briefing files

1. Never write "compliant". Write "no gap found".
2. Use the risk tier from the matching file in `assessments/`. Do not change it or restate it more strongly.
3. Set the red/amber/green rating from the risk tier:
   - Red: prohibited, high-risk.
   - Amber: transparency only, needs lawyer.
   - Green: minimal, out of scope.
